# ATPRO

Agricultural Transport Route Optimization (ATPRO) is an academic project for coordinating agricultural transport between farmers and drivers.

## Scope

The planned system has Farmer, Driver, and Admin roles. Its core workflow includes transport requests, compatible vehicle matching, capacity-aware trip assignment, driver acceptance, pickup and delivery tracking, and pickup route optimization using Clarke-Wright Savings with 2-opt improvement.

## Development

Implementation will be delivered incrementally. The initial landing/role-selection and authentication prototypes have been prepared separately and will be integrated into this repository following source review and verification.

This README initializes the repository and confirms GitHub write access; it does not indicate that the application has been deployed.
